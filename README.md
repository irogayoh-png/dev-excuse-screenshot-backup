One funny single-line excuse a developer gives when code breaks in production, under 200 characters. The program writes it to `/output/entry.txt`.

Final line: `The rollback failed because the backup was a screenshot of the database.` (72 characters) — the safety net itself failed, and the reveal is that the "backup" was a screenshot: a deadpan confession, one vivid absurd image, jargon used right, nothing trimmable.

It was picked by arena, not by rubric: 16 candidates across five angles, shortlisted to 6, every pair fought both ways round under the judge's published brief. The champion won all 5 of its pairs, then beat each of the three real top-10 lines from the same "Make the AI Judge Laugh" lane both ways round. The full table is in `main.py`.

## Run it

```sh
python3 main.py
```

Python 3.13, stdlib only, no dependencies. Deterministic: same line on every run.
